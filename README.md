# Horde Survival Prototype

### Overview
This project is as a Windows-only game prototype built in Unity for learning purposes. It is a single prototype build with no planned future development.

## Controls
**WASD** - Move

**Mouse** - Aim

**Left Click** - Primary attack

**Right Click** - Secondary attack

**Esc** - Pause menu (in-game)
